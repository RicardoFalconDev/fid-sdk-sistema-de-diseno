Qué es

Es la referencia completa para diseñar e implementar el SDK de FID: los fundamentos visuales, los componentes, la personalización de marca, la accesibilidad y el código. Todo sale de los tokens del archivo de Figma “FID SDK — Variables”; si algo de acá contradice a Figma, gana Figma.

Fundamentos

Color, tipografía, espaciado, radios y bordes, íconos, ilustraciones y Lotties.

Tokens en las pantallas

Todas las pantallas del SDK, flujo por flujo, con el token de cada parte.

Personalización

Las cuatro propiedades que define cada cliente y cómo se aplican en el SDK.

Calidad

Accesibilidad, contraste y la lista de verificación antes de entregar.

Tres capas de tokens

Un token es un nombre que apunta a un valor. El código usa el nombre y nunca el valor. Hay tres capas y solo la del medio se usa en componentes.

1 · PrimitivoColor crudo de una escala de 12 pasos. Es materia prima.
--indigo-9: #2A39D0
2 · Semántico se usa en componentesDice para qué sirve, no cómo se ve.
--button-primary-bg: var(--accent-9)
3 · ComponenteEl CSS que escribís.
background: var(--button-primary-bg)

Cómo se nombran

De Figma al CSS, las / pasan a - y se antepone --: button/primary-bg-hover es --button-primary-bg-hover. Se nombra por rol, nunca por color.

--buttongrupo-primaryrol-bgparte-hoverestado

Reglas

Valen para personas y para agentes de IA.

    Qué cambia y qué no
    
  
    
    
    Cambia con primary
    --accent-1…12, --brand-*, --stroke-primary, --stroke-brand-subtle, --text-brand, --button-primary-bg(-hover), --button-tertiary-*, ilustraciones y Lotties de marca.
    
    
    Cambia con primaryText
    Solo --button-primary-text: el texto de los botones primarios y el tilde de las casillas.
    
    
    No cambia nunca
    Jerarquía de texto, fondos y bordes neutros, estados, links, botones secundario, de peligro y deshabilitado, espaciado, radios (salvo --radius-button), tamaños y estilos de texto.

    Aplicar la marca
    
  
    Las variables se escriben en el contenedor del SDK, no en el :root de la página del cliente.
    
  
    javascript
    var RADII = { xs: 4, s: 8, m: 16, full: 999 };
var HEX = /^#([0-9a-f]{3}|[0-9a-f]{6})$/i;

function applyBranding(frame, cfg) {
  var primary = HEX.test(cfg.primary) ? cfg.primary.toUpperCase() : '#2A39D0';
  var text = HEX.test(cfg.primaryText) ? cfg.primaryText.toUpperCase() : '#FFFFFF';
  var radius = cfg.radius === 'custom' ? cfg.radiusCustom : RADII[cfg.radius];
  frame.style.setProperty('--accent-9', primary);
  frame.style.setProperty('--button-primary-text', text);
  frame.style.setProperty('--radius-button', radius + 'px');
  frame.style.setProperty('--font-family-default',
    cfg.font === 'system' ? 'system-ui' : "'" + cfg.font + "'");
}
    
  
    La cascada importatokens.css declara los semánticos en :root y en .sdk-frame. Si solo estuvieran en :root, --button-primary-bg usaría el --accent-9 de la raíz y no vería el color del cliente. El contenedor lleva la clase sdk-frame y accent-from-primary.css se carga después de tokens.css.
    
  
    Con font
    
  
    Cargá la fuente elegida bajo demanda y mantené system-ui de respaldo. Roboto y Lato no tienen peso 600 (usá 700); Open Sans y Lato no tienen 500 (usá 400).
    
 
    

    




    
 
    
  
    Introducción
    
  
    El color del SDK tiene dos partes. Una es la identidad de FID, igual en todas las integraciones: los grises, los estados y la estructura de cada pantalla. La otra es un único color de marca que define cada cliente y que el SDK aplica en las acciones y en los acentos.
    
  
    
  
    Anatomía del color
    
  
    Los neutros llevan la mayor parte de la pantalla: texto, fondos y bordes. El color de marca aparece solo donde hay acción o un acento. Los colores de estado son fijos y nunca toman la marca.
    
  
    Pasá el mouse por cada punto de la lista para ver dónde está en la pantalla.

      Cómo usarla

      Reclasificar un Lottie
      
  
      Se dibuja con lottie-web en modo SVG y se llama a tintLottie() en DOMLoaded y en cada enterFrame.
      
  
      js/tint-lottie.js
      function lottiePrimaryClass(value) {
  var m = /rgb\(\s*(\d+)\s*,\s*(\d+)\s*,\s*(\d+)/.exec(value || '');
  if (!m) return null;
  var r = +m[1], b = +m[3];
  if (b - r < 60) return null;        // gris, blanco, negro
  return r > 120 ? 'lt-primary-50' : 'lt-primary';
}

function tintLottie(holder) {
  holder.querySelectorAll('[fill], [stroke]')
    .forEach(function (node) {
      ['fill', 'stroke'].forEach(function (prop) {
        var cls = lottiePrimaryClass(node.getAttribute(prop));
        if (cls) node.classList.add(cls, 'lt-' + prop);
      });
    });
}

                                                                                  Niveles WCAG
                                                                                  
  
                                                                                  
    
                                                                                  ANivel mínimoEl piso de accesibilidad.
                                                                                  
    
                                                                                  AADesde 4.5:1El estándar más habitual que exigen leyes y normativas, como la European Accessibility Act y la norma EN 301 549.
                                                                                  
    
                                                                                  AAADesde 7:1El nivel máximo y más exigente.
                                                                                  
  
                                                                                  
  
                                                                                  El texto normal necesita 4.5:1. El texto grande, los íconos y los bordes de los componentes necesitan 3:1. El color nunca es la única forma de transmitir información.
                                                                                  
  
                                                                                  Probá una combinación
                                                                                  
  
                                                                                  El panel muestra un único aviso que compara el texto del botón contra el color principal. Informa, nunca bloquea.
                                                                                  
  
                                                                                  
    
                                                                                  
    
                                                                                  
  
                                                                                  
  
                                                                                  
  
                                                                                  Contraste de los tokens
                                                                                  
  
                                                                                  TextoFondoContrasteNivel
                                                                                  
  
                                                                                  Calculado con los valores por defecto y redondeado a un decimal. El aviso del panel trunca a un decimal.
                                                                                  
 
                                                                                  
 
                                                                                  
  
                                                                                  El cálculo
                                                                                  
  
                                                                                  javascript
                                                                                  function luminance(hex) {                       // luminancia relativa WCAG
  var h = hex.length === 4 ? '#' + hex[1] + hex[1] + hex[2] + hex[2] + hex[3] + hex[3] : hex;
  var c = [1, 3, 5].map(function (i) {
    var v = parseInt(h.slice(i, i + 2), 16) / 255;
    return v <= 0.03928 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4);
  });
  return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
}
function contrast(a, b) {                      // solo informativo: sirve para armar el aviso de accesibilidad
  var la = luminance(a), lb = luminance(b);
  return (Math.max(la, lb) + 0.05) / (Math.min(la, lb) + 0.05);
}
function wcagLevel(ratio) {                     // nivel alcanzado para texto normal
  return ratio >= 7 ? 'AAA' : ratio >= 4.5 ? 'AA' : null;
}
function a11yNotice(primaryText, primary) {     // aviso del panel: primaryText contra primary
  var ratio = contrast(primaryText, primary);
  var shown = (Math.floor(ratio * 10) / 10).toFixed(1) + ':1';   // truncado a 1 decimal
  var level = wcagLevel(ratio);
  return {
    passed: level !== null,
    message: level
      ? 'WCAG ' + level + '✓ (' + shown + ') Calificación aprobada.'
      : 'WCAG AA × (' + shown + ') Calificación no aprobada. El texto puede ser difícil de leer.'
  };
}
